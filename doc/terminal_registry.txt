1. Introduction                              *terminal_registry-introduction*

The terminal_registry plugin provides a way to manage multiple terminal
buffers in Neovim. It provides a function to start terminals with specific
IDs and utility functions to manipulate them.

Features:

- Register terminal buffers with custom IDs
- Reuse existing terminal buffers
- Send input to registered terminals
- Query terminal status and output

==============================================================================
2. Functions                                    *terminal_registry-functions*

------------------------------------------------------------------------------
2.1 terminal_registry#start({cmd} [, {opts}])    *terminal_registry#start()*

Start a terminal with the given command and register it in the registry.

Parameters:~
  {cmd}   String. The command to execute in the terminal.
  {opts}  Dictionary (optional). Configuration options:
          - id: String. Unique identifier for this terminal.
                Default: {cmd}
          - kill: Boolean. If 1 and a terminal with this ID exists,
                  kill the old terminal before starting a new one.
                  Default: 1
          - terminal_options: Dictionary. Options to pass to |termopen()|.
                             Default: {}

Returns:~
  Dictionary with 'jobid' and 'bufnr' keys on success.
  Nothing if failed (error message will be displayed).

Example:~
>
  " Start a shell with default ID ('bash')
  call terminal_registry#start('bash')

  " Start a longer command with a custom ID
  call terminal_registry#start('python manage.py runserver',
      \ {'id': 'django'}
      \ )
<

------------------------------------------------------------------------------
2.2 terminal_registry#switch({id})              *terminal_registry#switch()*

Switch to the buffer of a registered terminal.

Parameters:~
  {id}  String. The ID of the registered terminal.

Example:~
>
  call terminal_registry#switch('django')
<

------------------------------------------------------------------------------
2.3 terminal_registry#send({id}, {keys})          *terminal_registry#send()*

Send input to a registered terminal without appending a newline.

Parameters:~
  {id}    String. The ID of the registered terminal.
  {keys}  String. The text to send to the terminal.

Example:~
>
  " Execute shell command
  call terminal_registry#sendl('bash', "ls -la\n")
<

------------------------------------------------------------------------------
2.4 terminal_registry#sendl({id}, {keys})        *terminal_registry#sendl()*

Like |terminal_registry#send()|, but appends a newline to the input.

Parameters:~
  {id}    String. The ID of the registered terminal.
  {keys}  String. The text to send to the terminal.

Example:~
>
  " Execute shell command
  call terminal_registry#sendl('bash', 'ls -la')
<

------------------------------------------------------------------------------
2.5 terminal_registry#has_started({id})    *terminal_registry#has_started()*

Check if a terminal with the given ID has been started.

Parameters:~
  {id}  String. The ID to check.

Returns:~
  1 if a terminal with this ID exists in the registry, 0 otherwise.

Example:~
>
  if terminal_registry#has_started('python-repl')
    call terminal_registry#switch('python-repl')
  else
    call terminal_registry#start('python', {'id': 'python-repl'})
  endif
<

  {id}  String. The ID of the registered terminal.

Returns:~
  Integer. The buffer number of the terminal.
<

------------------------------------------------------------------------------
2.7 terminal_registry#get_recent_output_lines({id}, {n})
                               *terminal_registry#get_recent_output_lines()*

Get the last N lines of output from a registered terminal, excluding
trailing empty lines.

Parameters:~
  {id}  String. The ID of the registered terminal.
  {n}   Integer. Number of lines to retrieve.

Returns:~
  String. The last N lines joined with newlines.

Example:~
>
  " Get last 100 lines of server logs
  terminal_registry#get_recent_output_lines('django', 100)
<

Get a list of all registered terminal IDs.

Returns:~
  List of strings. All registered terminal IDs.
<

2.9 terminal_registry#dump()                      *terminal_registry#dump()*

<

------------------------------------------------------------------------------
2.10 terminal_registry#unregister({id})      *terminal_registry#unregister()*

Remove a terminal from the registry. This is called automatically when the
terminal buffer is deleted.

Parameters:~
  {id}  String. The ID of the terminal to unregister.

Example:~
>
  call terminal_registry#unregister('bash')
<
