# nvim-terminal-registry

A Neovim plugin to manage multiple terminal buffers. It provides a function to
start terminals with specific IDs and utility functions to manipulate them.

## Installation

For example, using [vim-plug](https://github.com/junegunn/vim-plug):

```vim
Plug 'igrep/nvim-terminal-registry'
```
